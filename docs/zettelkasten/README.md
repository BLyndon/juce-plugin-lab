# Zettelkasten

Ideas for this repository that have no time slot yet, captured one idea per note, linked, and pruned until something valuable remains. Results grow out of it into the rest of the repository.

## Find an idea

Start with a structure note from [structure-notes.md](structure-notes.md) and follow the links. Each structure note orders the zettels of one topic.

## Add an idea

1. Drop a raw draft: say it in a Claude session, or put it as a file into [inbox/](inbox/). Rough wording is fine.
2. Claude turns it into one or more zettels: one idea each, with a statement as heading, a file name, and links to related zettels. The meaning stays yours.
3. Review Claude's part.

## Status

Every zettel has a status line:

- `open`: not decided yet
- `done`: the idea became a result outside the zettelkasten; the zettel links to it
- `rejected`: dropped; the zettel states the reason

Zettels are never deleted because they are done or rejected, so the reasons stay.

## Review

At the start and at the end of a weekend session, when there is time: read the open zettels, then start one, reject one, or leave them. Claude can propose merges and rewrites; you decide.
