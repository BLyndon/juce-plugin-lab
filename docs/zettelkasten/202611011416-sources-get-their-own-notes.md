# Ideas taken from a source get a literature note of their own

Status: open

When an idea comes from a source (a book, documentation, a reference plugin), the source's statement is captured in a literature note in my own words, with the exact reference. The zettel that builds on it states my own thought and links to the literature note. This keeps what the source says apart from what I conclude, and the source can be found again.
