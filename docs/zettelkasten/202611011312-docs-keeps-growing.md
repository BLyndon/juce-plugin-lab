# docs/ keeps growing and needs a structure

Status: open

Every plugin adds documents to `docs/`: theory companions, guides, references. Without a structure it gets harder to find a document and to decide where a new one belongs, and documents drift into each other's roles. Example: the stereo-pan spec filled up with theory until the theory was moved into its own companion document.
