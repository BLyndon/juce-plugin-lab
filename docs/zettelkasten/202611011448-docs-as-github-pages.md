# Publishing docs/ as GitHub Pages is a later stage of the docs/ structure

Status: open

If `docs/` keeps growing this fast, reading it as plain Markdown files in the repository gets harder. Publishing it as GitHub Pages, a rendered website with navigation, would be the next stage. It is deliberately not planned yet: first the structure of the documents has to settle.
